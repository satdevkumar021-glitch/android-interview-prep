# Security

Report suspected vulnerabilities privately to the maintainer through LinkedIn: https://www.linkedin.com/in/satdevsokhal/ . Do not include credentials in public issues. No guaranteed response time is promised.

Never commit API keys, access tokens, signing keys, personal records, or employer/client code. Revoke exposed credentials immediately; deleting a file is insufficient. Educational examples and demo authentication are not production security controls. The MIT license is permission to reuse, not a security certification.
