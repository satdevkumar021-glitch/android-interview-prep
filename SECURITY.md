# Security

Use GitHub's private vulnerability reporting from the repository Security tab: https://github.com/satdevkumar021-glitch/android-interview-prep/security/advisories/new . If unavailable, contact the maintainer through LinkedIn: https://www.linkedin.com/in/satdevsokhal/ . Do not include credentials in public issues. No guaranteed response time is promised.

Never commit API keys, access tokens, signing keys, personal records, or employer/client code. Revoke exposed credentials immediately; deleting a file is insufficient. Educational examples and demo authentication are not production security controls. The MIT license is permission to reuse, not a security certification.
