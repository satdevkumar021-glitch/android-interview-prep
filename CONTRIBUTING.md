# Contributing

Open an issue describing the proposed change, then submit a focused pull request. Follow the README setup instructions and document validation actually performed. Do not claim tests passed without running them.

Use only code and material you have permission to contribute. Preserve third-party license notices. Never submit employer/client-confidential code, credentials, or personal data. AI-assisted changes require human review for accuracy, security and licensing. Technical teaching claims should cite official documentation and identify relevant versions.

Contributions to original project code are under the MIT license. Third-party material remains governed by its own license.
